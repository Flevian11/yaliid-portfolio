# YaliID Portfolio API
Laravel 13 API backend for the YaliID portfolio and service platform.

## Domains
Profile, social links, experience, achievements, recommendation letters, education, certifications, skills, projects, services, service requests, advertisements, testimonials, messages and settings.

## API
Public endpoints are under `/api/v1`. Admin CRUD routes are protected by Laravel's `auth` middleware and are intended to be connected to the chosen admin authentication strategy.

Run migrations only after reviewing the schema.
